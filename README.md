# Mohammed Mahmood — Portfolio

Personal portfolio for Mohammed Mahmood, Frontend Developer and Co-Founder at ORVEN.

## Stack
React 18, TypeScript, Vite 5, Tailwind CSS, shadcn/ui and React Router. The existing stack and dependency versions are retained.

## Development

```sh
npm ci
npm run dev
npm run build
npx tsc --noEmit -p tsconfig.app.json
```

## Selected work
- Spiky: Arabic coaching platform; links to the public ORVEN case study. Repository remains private.
- AL-Araby Oils: personal e-commerce frontend demo, explicitly described as frontend only with no connected backend or payment processing.

Project descriptions are grounded in the repositories’ READMEs and ORVEN’s published case study. No client metrics, testimonials or unverified outcomes are claimed.

## Publishing
GitHub Pages serves the `gh-pages` branch. Run `npm run build` then `npm run deploy` after committing and pushing source changes. Vite and React Router retain the `/mohamed-webdev-Portfolio/` base path.
